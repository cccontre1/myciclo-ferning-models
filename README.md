# MyCiclo: Ferning Pattern Classification Models 🔬

Welcome to the central codebase for **MyCiclo's AI layer**. This open-source project aims to automate the detection and classification of salivary ferning patterns (a key biomarker for the fertile window) using computer vision and machine learning.

## 📂 Architecture & Data
This repository will host the training scripts, model architectures (PyTorch/TensorFlow), and the inference API for the classification models. 

> **Note on the Dataset:** To ensure optimal version control and data privacy, our proprietary crowdsourced dataset of +1,000 biological images will be hosted in a separate dedicated repository (`myciclo-ferning-dataset`) and platforms like Hugging Face. The data loaders in this repository will pull directly from those sources once published.

## 🚀 Project Roadmap (Next 12 Months)
This initiative is structured to transition our community-validated hardware (EVA microscope) into an AI-driven digital platform:
- **Phase 1 (Months 1-3):** Data infrastructure setup and clinical labeling of the 1,000-image dataset to establish a robust ground truth.
- **Phase 2 (Months 4-6):** Training and validation of baseline computer vision models.
- **Phase 3 (Months 7-9):** Development of the MVP digital interface for real-time inference.
- **Phase 4 (Months 10-12):** Closed beta pilot with 300 users and global open-source release of model weights and datasets.
